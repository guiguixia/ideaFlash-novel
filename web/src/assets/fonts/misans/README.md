# MiSans Font Asset

Source: https://hyperos.mi.com/font/zh/download/

Bundled files:

- `MiSansVF.ttf`: extracted from the official `MiSans.zip` package, variable font build; kept as the unmodified source of record.
- `MiSansVF.woff2`: full-glyph WOFF2 delivery build generated from `MiSansVF.ttf` for renderer packaging. It is not subsetted.
- `MiSans-License.pdf`: official MiSans font intellectual property license agreement.

License notes for product use:

- Novel must explicitly note that it uses MiSans.
- Do not modify, adapt, redevelop, or glyph-subset the official font source file.
- Do not distribute the font software as a standalone asset.
