# 角色全书记忆实验

该实验是独立服务，不修改或导入桌面端业务代码。启动桌面端后，在项目根目录执行：

```bash
backend/.venv/bin/python experiments/role-memory/server.py
```

然后打开 `http://127.0.0.1:8765/`。

实验服务仅读取桌面端默认 SQLite 数据库（也可通过 `NOVEL_DATABASE_URL` 指定），列出已导入的作品及全部章节；选择一个“当前章节”、输入人物名并提问，即可验证角色能否从该作品开篇到当前章节的向量知识库中检索记忆。

- 不创建副本、角色卡或私聊会话，也不写入业务数据库。
- 必须先在桌面端为作品构建完成“角色知识库”。
- 所选章节是严格的时间上限：后续章节不会被检索，避免剧透。
- 页面会显示本轮检索到的原文片段，便于核验回答是否有依据。
- 页面仅在浏览器内保存最近 8 条问答；这些内容会以“角色 / 上下文 / 本轮问题”参与 RAG 查询，并与 RAG 原文证据一起发送给模型。刷新、切换作品、章节或人物时会清空，不写入任何数据库。
